# Forma (vertiqal) — ChatGPT directory starter prompts

User-language Example Prompts for the directory listing. Free Fit Passport tools only. No pricing, trials, or Solari/checkout CTAs in the listing blurb.

1. **Will these fit me?** Here's my Fit Passport — check this running shoe against my measurements.
2. **Read my Fit Passport** and tell me my size, sport, and the attributes my shoes need.
3. **Does this climbing shoe suit me?** Check "La Sportiva Solution Comp" against my passport.
4. **Compare two shoes** for my passport — which is the better fit and why?
5. **I got this passport link from Forma** — summarize it so another shop can use my fit.

Film-a-clip measurement, live Solari size checks, and Buy handoff stay on [vertiqal.vercel.app](https://vertiqal.vercel.app) — not as in-chat deep actions.
